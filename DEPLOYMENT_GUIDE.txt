====================================================================
ABUNDANCE CRM - DEPLOYMENT GUIDE
Complete step-by-step instructions to deploy to GitHub & DigitalOcean
====================================================================

PREREQUISITES
=============
✓ GitHub account: Vinewoodagency (github.com/Vinewoodagency)
✓ GitHub Personal Access Token created (should start with ghp_)
✓ DigitalOcean account (cloud.digitalocean.com)
✓ Docker & Docker Compose installed locally (optional for testing)

====================================================================
STEP 1: EXTRACT & PREPARE THE CODEBASE
====================================================================

Run these commands on your Mac (in Terminal/iTerm):

# 1a. Check if the codebase is in Downloads
ls -la ~/Downloads/ | grep abundance

# 1b. If you see abundance-codebase.zip, extract it
cd ~/Downloads
unzip -o abundance-codebase.zip -d abundance-system

# 1c. Verify extraction (should see 25+ files)
ls -la ~/Downloads/abundance-system/

# Expected output: main.py, models.py, App.tsx, docker-compose.yml, etc.

====================================================================
STEP 2: MOVE TO DESKTOP & INITIALIZE GIT
====================================================================

# 2a. Move the extracted folder to Desktop
rm -rf ~/Desktop/abundance-system  # Remove old placeholder if exists
mv ~/Downloads/abundance-system ~/Desktop/abundance-system

# 2b. Enter the folder
cd ~/Desktop/abundance-system

# 2c. Verify the real code is there
ls -la | head -20

# Expected: You should see main.py, package.json, docker-compose.yml, etc.

# 2d. Initialize git repository
rm -rf .git  # Remove old git history if it exists
git init

# 2e. Add GitHub remote
git remote add origin https://github.com/Vinewoodagency/abundance-system.git

====================================================================
STEP 3: PUSH CODE TO GITHUB
====================================================================

# 3a. Stage all files
git add -A

# 3b. Make initial commit
git commit -m "Add complete Abundance CRM - FastAPI backend, React frontend, Docker, PostgreSQL"

# 3c. Push to GitHub main branch
git push -u origin main

# When prompted:
# Username: Vinewoodagency
# Password: [PASTE YOUR GITHUB PERSONAL ACCESS TOKEN HERE]
#          (Token should start with ghp_)

# WAIT: Watch for "Counting objects...", "Compressing objects...", then success message
# If stuck on password, press Ctrl+C and try again

====================================================================
STEP 4: VERIFY GITHUB UPLOAD
====================================================================

# 4a. Check git status
git status

# Should show: On branch main, nothing to commit, working tree clean

# 4b. Verify remote
git remote -v

# Should show: origin https://github.com/Vinewoodagency/abundance-system.git

# 4c. Check GitHub in browser
# Navigate to: https://github.com/Vinewoodagency/abundance-system
# You should see all files (main.py, App.tsx, docker-compose.yml, etc.)

====================================================================
STEP 5: DEPLOY TO DIGITALOCEAN APP PLATFORM
====================================================================

# 5a. Open DigitalOcean in browser
# Go to: https://cloud.digitalocean.com/apps/new

# 5b. Connect Repository
# - Click "GitHub" as source
# - Select: Vinewoodagency/abundance-system
# - Branch: main
# - Click "Next"

# 5c. Auto-Detect Components
# DigitalOcean should detect:
# - Backend Service (from Dockerfile)
# - Frontend Service (from Dockerfile.frontend)
# - Database (PostgreSQL)
# 
# If nothing detected, check GitHub has real code pushed (not placeholders)

# 5d. Configure Environment Variables
# In the DigitalOcean panel, add these env vars:

# ENV = production
# DEBUG = False
# SECRET_KEY = [Generate: openssl rand -base64 32]
# ALLOWED_ORIGINS = https://abundance-crm-[your-app-id].ondigitalocean.app
# DATABASE_URL = [DigitalOcean PostgreSQL connection string - provided]
# VITE_API_URL = https://abundance-crm-[your-app-id].ondigitalocean.app

# 5e. Review & Deploy
# - App name: abundance-crm
# - Region: New York (NYC)
# - Click "Create Resources"
# - WAIT 5-10 minutes for build & deployment

====================================================================
STEP 6: TEST LIVE DEPLOYMENT
====================================================================

# 6a. Open the live app in browser
# DigitalOcean will provide a URL like:
# https://abundance-crm-xyz123abc.ondigitalocean.app

# 6b. Test health endpoint
curl https://abundance-crm-xyz123abc.ondigitalocean.app/api/health

# Should return: {"status":"healthy","service":"abundance-crm","timestamp":"..."}

# 6c. Test frontend
# Open browser: https://abundance-crm-xyz123abc.ondigitalocean.app
# You should see the Abundance CRM dashboard

# 6d. Test API documentation
# Open: https://abundance-crm-xyz123abc.ondigitalocean.app/docs
# Should show Swagger interactive API documentation

====================================================================
STEP 7: CONTINUOUS DEPLOYMENT (AUTOMATIC)
====================================================================

From now on, every time you push to GitHub main branch:
- DigitalOcean automatically detects the change
- Rebuilds Docker containers
- Deploys new version (5-10 min)
- Zero downtime

To push updates:
cd ~/Desktop/abundance-system
git add -A
git commit -m "Update: [describe changes]"
git push origin main

====================================================================
TROUBLESHOOTING
====================================================================

Q: "fatal: 'origin' does not appear to be a git repository"
A: You're not in the project folder. Run: cd ~/Desktop/abundance-system

Q: "Repository not found" when pushing
A: Check GitHub token is valid. Generate new one at:
   https://github.com/settings/personal-access-tokens/new
   Paste new token when prompted for password

Q: DigitalOcean says "No components detected"
A: GitHub push may not have real code. Check:
   https://github.com/Vinewoodagency/abundance-system
   Should see main.py, App.tsx, docker-compose.yml, etc.
   If only placeholders, re-push with Step 3

Q: "Connection refused" when accessing API
A: Deployment still in progress. Check build logs in DigitalOcean:
   App Platform > your-app > Deployments > View Details

Q: Frontend can't reach backend
A: Check VITE_API_URL env var matches your live domain
   Should be: https://abundance-crm-[id].ondigitalocean.app
